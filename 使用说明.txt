GPT 生图工坊（打包版）
================================

使用步骤
--------------------------------
1. 双击 GptImageStudio.exe 启动原生桌面客户端，不打开浏览器，也不显示控制台窗口。
2. 在客户端内填写两项配置（程序不内置，默认都是空的）：
   API Key：你的中转站 key，例如 sk-xxxxxxxx
   提供商地址（Base URL）：例如 https://你的中转站地址/v1
   如需下次自动带出，勾选“记住 Base URL、API Key 与模型”。
3. 点击“刷新模型”，在“模型”下拉框选择后即可开始生图。
   程序只列出上游的 gpt-image-* 模型（例如 gpt-image-2、gpt-image-2.5-flare、
   gpt-image-2.5-sunburst），不会列出或调用 DALL-E、Doubao-Seedream、Gemini。

参数说明
--------------------------------
- 画幅固定为官方 10 档：1:1 / 16:9 / 9:16 / 3:2 / 2:3 / 4:3 / 3:4 / 5:4 / 4:5 / 21:9。
  不支持 auto 与自定义像素，避免上游静默回退到 1:1。
- 分辨率 1K / 2K / 4K，默认 1K。每个组合直接下发官方推荐像素，
  例如 16:9 + 2K -> 2560x1440，21:9 + 4K -> 3808x1632。
- 质量随档位自动映射：1K -> standard、2K -> hd、4K -> 4k，不需要手动选择。
- 数量可选 1~4 张；上传参考图后按图生图调用，数量自动固定为 1 张，最多 4 张参考图。
- 1K 档最省积分也最快（gpt-image-2 约 15~30 秒），2K / 4K 更慢也更贵，建议先用 1K 试提示词。

生成过程
--------------------------------
- 提交后立刻返回任务 ID，客户端按秒显示“生成中 xx%（已用 xx 秒）”。
- 中转站支持异步任务时显示上游的真实进度；只支持同步的中转站按已用时间估算进度
  （约 120 秒视为接近完成，到 95% 后保持不变直到真正出图）。
- 生成中可点击“取消等待”停止轮询；上游可能仍在生成。
- 单次生成预算 15 分钟，超时会提示失败；完成或失败的任务保留 30 分钟后自动清理。

配置说明
--------------------------------
- 提供商地址与 API Key 只在桌面客户端内填写。
- 勾选“记住 Base URL、API Key 与模型”后，三项会使用 Windows DPAPI 加密保存到 exe 同级的
  client-credentials.dat；该文件只能由当前 Windows 用户解密，取消勾选会立即删除。
- 不勾选时两项只保存在当前运行期间，关闭程序后需要重新填写。
- exe 内不含任何 key 与中转站地址；两项没填时程序不会向任何服务器发请求。
- 清空其中任意一项，状态会提示待配置，生成按钮不可用。

其它
--------------------------------
- 生成的图片保存在 exe 同级 outputs\generated 目录。
- 生图历史保存在 exe 同级 outputs\history.json。
- 结果区显示的尺寸是图片文件的真实像素。
- 需要走本机代理：启动前设置环境变量 HTTP_PROXY / HTTPS_PROXY。
- 窗口较矮时，左侧控制区可上下滚动（鼠标滚轮或右侧滚动条），提示词输入框内的滚轮仍然用于查看文本。
- 关闭客户端窗口即可停止程序和内部服务。
- 常见报错：401 多为 key 不对或地址填成了官方接口；404 多为地址少了 /v1；
  524 是中转站代理超时，稍后重试或改用 1K 档。

重新打包（开发者）
--------------------------------
回到源码目录，运行 .\build.ps1 即可重新生成 dist\GptImageStudio.exe，
脚本会同时把本说明复制到 dist 目录。
