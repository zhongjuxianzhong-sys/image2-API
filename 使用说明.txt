Image2 生图工坊（打包版）
================================

使用步骤
--------------------------------
1. 双击 Image2Studio.exe 启动，保持黑色控制台窗口打开。
2. 浏览器打开 http://127.0.0.1:8787
3. 在页面下方填写两项配置（程序不内置，默认都是空的）：
   API Key：你的中转站 key，例如 sk-xxxxxxxx
   提供商地址（Base URL）：例如 https://你的中转站地址/v1
4. 两项填好后会自动获取中转站支持的生图模型，在“模型”下拉框选择后即可开始生图。
   支持 GPT Image、DALL-E 与 Doubao-Seedream；不同模型的尺寸、质量和参考图能力会自动切换。
   画幅可选“自定义比例”，填写如 21:9 后会按所选分辨率档推导实际像素。
   GPT Image 2 / 2.5 的 1K / 2K / 4K 会自动映射为上游推荐像素与 standard / hd / 4k 质量档。

配置说明
--------------------------------
- 提供商地址与 API Key 只在网页界面填写，不需要任何配置文件。
- 两项保存在本机浏览器的 localStorage 里，下次打开自动带出；换浏览器或换电脑需要重新填写。
- exe 内不含任何 key 与中转站地址；两项没填时程序不会向任何服务器发请求。
- 清空其中任意一项，状态灯会提示“待配置”。

其它
--------------------------------
- 生成的图片保存在 exe 同级 outputs\generated 目录。
- 生图历史保存在 exe 同级 outputs\history.json。
- 换端口：在命令行执行 Image2Studio.exe --port 8123（默认 8787）。
- 需要走本机代理：启动前设置环境变量 HTTP_PROXY / HTTPS_PROXY。
- 常见报错：401 多为 key 不对或地址填成了官方接口；404 多为地址少了 /v1；
  524 是中转站代理超时，稍后重试或降低质量/尺寸。

重新打包（开发者）
--------------------------------
回到源码目录，运行 .\build.ps1 即可重新生成 dist\Image2Studio.exe，
脚本会同时把本说明复制到 dist 目录。
